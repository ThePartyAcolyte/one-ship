# Spec 21: Agent Pixel Portrait DNA & Compositor System

## 1. Overview & Objectives

Every AI agent persona in **ONE-SHIP** represents a developer specialist or architecture coordinator. To enhance visual identity without breaking the platform's developer metaphor, this specification introduces a **deterministic Pixel Portrait DNA engine**.

Portraits are generated by compositing transparent PNG layers on a fixed **64×96 pixel** base canvas. Each portrait's combination of base skin, facial expression, hair style/color, facial hair, and accessories is encoded as a deterministic DNA string (e.g., `B02:E0:H04:BD02:A05`).

---

## 2. Asset Library Sanitization & Structure

The input library in `extras/` contains layered pixel art assets. Non-human fantasy assets (aliens, minotaurs, orcs, skeletons, birds, frogs, wolves) are excluded to preserve the application's developer metaphor.

### 2.1 Asset Filtering Rules
- **EXCLUDE:** `extras/Pixel-Portraits-Addon/Legacy-Pack/{Bird, Frog, Minotaur, Orc, Skeleton, Wolf}` and non-human accessories (nose rings, tusk rings, skeleton items).
- **INCLUDE:** Human skin bases, human expressions, hair styles/colors, beards, glasses, hats, bandanas, chains, reading glasses.

### 2.2 Base Frame & Grid Geometry
- **Tile Dimensions:** Width = 64px, Height = 96px.
- **Single Assets:** Individual PNG images of 64×96px.
- **Sprite Sheets:** Composite sheets (e.g., `Feminine_A-sheet.png`, `Blue_hair-sheet.png`, `Sheet.png`) parsed on 64×96 tile boundaries.

### 2.3 Asset Catalog Manifest (`public/portraits/manifest.json`)
Assets are categorized into five ordered rendering layers (bottom to top):
1. `base`: Human skin tone & head shape (`B01` - `B14`; masculine: `B01`–`B04`, `B07`–`B10`, `B13`–`B14`; feminine: `B05`, `B06`, `B11`, `B12`).
2. `expression`: Facial expression slots (`E0` = default, `E1` = happy, `E2` = sad, `E3` = annoyed, `E4` = angry, `E5` = surprised).
3. `beard`: Facial hair overlays (`BD00` = none, `BD01` - `BD05`). Suppressed automatically when the selected base is feminine.
4. `hair`: Hairstyle & hair color overlays (`H00` = bald, `H01` - `H21`).
5. `accessory`: Glasses, hats, bandanas, chains (`A00` = none, `A01` - `A16`).

---

## 3. DNA Encoding Format & Hashing

### 3.1 DNA String Schema
A portrait DNA string follows the colon-delimited format:
```
BASE_ID : EXPR_ID : HAIR_ID : BEARD_ID : ACC_ID
```
Example: `B02:E0:H04:BD01:A03`

### 3.2 Deterministic Random Generation
When an agent is initialized in `rula.toml` without a `dna` key:
1. The backend or randomizer selects random valid indices from each category in `manifest.json`.
2. The generated DNA string is persisted in `rula.toml` under `[agents.<id>] dna = "..."`.
3. The assigned DNA remains permanent across application restarts and user interactions unless explicitly modified.

## 4. Configuration Schema Extension (`rula.toml`)

The agent persona schema in `rula.toml` includes the optional `dna` string property:

```toml
[agents.bosmang]
accept_edits = true
args = []
auto_approve = true
context_docs = [".agents/personas/bosmang.md", "AGENTS.md"]
dna = "B01:E0:H06:BD02:A01"
effort = "high"
model = "gemini-3.8-flash"
role = "Lead Architecture & Systems Engineer"
runner = "agy"
system_prompt = "You are Bosmang..."
```

## 5. UI Rendering & Component Architecture

### 5.1 `<AppAgentPortrait />` Component
- **Props:**
  - `dna?: string | null`: DNA code (e.g. `B02:E0:H04:BD01:A03`). If omitted, `generateFallbackDna(agentId)` deterministically computes a valid DNA string.
  - `agentId?: string | null`: Agent persona identifier used for deterministic fallback DNA hashing.
  - `size?: number` (default: `48`): Rendered square edge in pixels (`1:1`), compositing a bottom-anchored `64×64` crop (`y = 32..96`) of each `64×96` sprite tile.
- **Canvas Rendering:** Uses HTML5 Canvas context 2D to draw each layer sequentially with `imageSmoothingEnabled = false` and CSS `image-rendering: pixelated;`.

### 5.2 UI Integration Points
- **Bottom Taskbar (`AgentTaskbar.vue`) & Floating Chat (`FloatingChatOverlay.vue`):** Renders pixel portrait badges alongside agent lifecycle status indicators.
- **Add/Edit Persona Modal (`AddPersonaModal.vue`):** Shows live preview of agent DNA and randomized preview button.
