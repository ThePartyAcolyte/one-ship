# Spec: Tray Hub Interface

> **Status: DEFERRED** — Feature specified but not yet implemented.
> Implementation tracker: Planned for post-0.2.x roadmap.

## 1. Compact Dashboard
*   The system tray icon spawns a compact floating window, not just a static text menu.
*   Displays a condensed view of active projects and quick-access buttons.

## 2. Omarchy Ethos
*   UI strictly follows the active Omarchy visual theme (colors/palette).
*   TUI-inspired aesthetics but fully functional with a mouse pointer.
