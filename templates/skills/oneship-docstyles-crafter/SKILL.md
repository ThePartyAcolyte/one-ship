# Custom Docstyle Crafter Protocol

This meta-skill guides the agent in collaborating with the developer to design a bespoke documentation standard tailored to the project's unique domain.

## 1. Operational Steps
1. **Interview & Requirements Gathering:**
   - Understand the team size, complexity, and compliance requirements.
2. **Design Directory Taxonomy:**
   - Propose an organized structure (e.g. `docs/rfcs/`, `docs/guides/`, `docs/api/`).
3. **Persist Custom Skill:**
   - Write `.agents/skills/custom-docstyle/SKILL.md` capturing the agreed rules.
4. **Scaffold Initial Docs:**
   - Create the root README/manifesto and initial templates.
