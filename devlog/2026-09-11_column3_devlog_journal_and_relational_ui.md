# Devlog: Column 3 Devlog Journal, Task Board, and Technical Debt UI (Spec 22)

**Date:** 2026-09-11  
**Topic:** Spec 22 Interactive Relational State UI & Column 3 Tri-Mode Switcher

---

## 1. Overview & Objectives

In this session, we completed the user interface for **Spec 22: Session Lifecycle, Database Devlog & Knowledge Graph**. With the backend relational tables and MCP tools already implemented and validated with clean database state, the goal was to provide a dedicated, brutalist, and reactive frontend surface in Column 3 (`ArtifactPanel.vue`) that allows developers to:
1. Browse chronological session devlogs generated by agents or manual entries.
2. Jump straight to touched files in the Reader or resume an agent's terminal execution within that exact past session context.
3. Manage active tasks (todos) with checkboxes, priority indicators, and inline creation.
4. Track technical debt items, view impact and remediation plans, and mark items as resolved.

---

## 2. Key Implementations

### A. Pinia Store Integration (`src/stores/dialogueStore.ts`)
- **Event Listeners:**
  - `SessionMinutesRecorded`: Automatically refetches session journals when an agent logs a milestone via MCP.
  - `AgentSessionResumed`: Automatically reloads the active continuous chat feed for the resumed agent.
  - `ProjectTodosUpdated`: Refetches project tasks upon external creation or status changes.
  - `TechnicalDebtUpdated`: Refetches project technical debt items upon new records or resolution.
- **Store Actions:**
  - `fetchSessionJournals(projectPath, agentId)`: Fetches up to 50 journal entries via `get_project_session_journals_cmd`.
  - `fetchProjectTodos(projectPath, statusFilter)`: Fetches project todos via `get_project_todos_cmd`.
  - `fetchProjectTechnicalDebt(projectPath, statusFilter)`: Fetches debt items via `get_project_technical_debt_cmd`.
  - `toggleTodoStatus(todoId, currentStatus)`: Toggles task status between `pending` and `completed` with optimistic local update.
  - `createProjectTodo(title, category, priority, description)`: Dispatches new task creation to backend SQLite.
  - `recordTechnicalDebt(title, impactSummary, remediationPlan, severity)`: Dispatches debt record creation to backend.
  - `resolveTechnicalDebt(debtId)`: Marks technical debt items resolved in SQLite.
  - `resumeSession(targetConversationId, reason)`: Invokes `resume_agent_session_cmd` and updates conversation turns.
  - `setJournalSubTab('devlog' | 'todos' | 'debt')`: Switches between the 3 sub-views.

### B. Devlog & Relational UI View (`src/components/dialogue/DevlogJournalView.vue`)
- Created a monospace brutalist component adhering strictly to `AGENTS.md` UI standards:
  - **Sub-Tab Navigation:** `Devlogs (<count>)`, `Tasks (<pending_count>)`, `Tech Debt (<open_count>)`.
  - **Search Bar:** Real-time query filter across devlog titles, summaries, tags, task titles, and debt summaries.
  - **Devlogs View:**
    - Cards displaying agent badge, title, timestamp, and linked `agy_conversation_id`.
    - Markdown-rendered summary and bulleted decision points.
    - Clickable touched-file badges: clicking a file opens it directly in Reader mode.
    - Contextual `[Resume]` button triggering in-place session revival in Herder.
  - **Tasks View:**
    - Filter row by status (`all`, `pending`, `completed`) and priority (`all`, `P1`, `P2`, `P3`).
    - Interactive checkbox toggling status between pending and completed.
    - Expandable "New Task" form using standardized `AppInput`, `AppSelect`, and `AppTooltip`.
  - **Technical Debt View:**
    - Filter row by status (`open`, `resolved`) and severity (`critical`, `high`, `medium`, `low`).
    - Highlighted severity tags with high-contrast color coding.
    - Impact summary card and remediation plan blocks.
    - Inline `[Resolve]` button.
    - Expandable "Record Technical Debt" form.

### C. Tri-Mode Column 3 Header (`src/components/dialogue/ArtifactPanel.vue`)
- Extended top header mode toggle to include **Journal** alongside **Reader** and **Terminal Log**:
  - `[Reader]` | `[Journal <total_count>]` | `[Terminal Log]`.
  - Contextual right-hand actions: the document picker and file copy buttons are shown in Reader mode, while DevlogJournalView provides dedicated contextual controls.
